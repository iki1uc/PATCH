# NC — Neural-Core / Intellekt-Router

## Zweck
NC ist die zentrale Intelligenzschicht des iki1uc-Systems.
Sie verbindet alle Hardware-Stationen (CPU, GPU, RAM, X4, CACHE)
mit Orbit-, IEO-, PX-, PQ- und ME-Stationen.

## Funktionen
- NC.vector erzeugen
- NC.link herstellen
- NC.net bereitstellen
- Respo-Werte interpretieren
- Score-Werte weiterreichen
- Orbit-Werte integrieren
- SYS-Dateien aktualisieren

## Wertigkeiten
- Vector
- Respo
- Link
- Net
